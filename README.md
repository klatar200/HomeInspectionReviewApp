# Home Inspection Review App

A review and discovery site for residential home inspectors, starting with new-build buyers near Plainfield, IL. Goal: help buyers find inspectors who are thorough and independent of the builder, and record documented cases where builders restrict or steer inspections.

Status: planning. See PLAN.md (scope, data model, wireframes, phases), DECISIONS.md (what was decided and why), RESEARCH.md (background and sources).
